# My Portfolio Page

## Overview
This portfolio page is a simple personal website built with HTML, CSS, and JavaScript. It includes a welcome modal, dark mode support, a dynamic skills list, and a projects section that loads content from session storage.

## Languages and Libraries
- HTML5
- CSS3
- JavaScript (vanilla)

## Dependencies and Setup
No external libraries or package installations are required to run this page.

1. Open the project folder in your browser.
2. Launch index.html directly or serve the folder with a simple local web server.
3. The page will load the projects section dynamically using browser session storage.

## Notes
The portfolio uses sessionStorage to save and retrieve project data so the project list can be restored on refresh during the current browser session.
